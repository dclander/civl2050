\subsection*{Homework Presentation}
Layout specifications:
\begin{enumerate}
\item Include a clear header on the first page with: name, homework number, date, and page numbers. Number pages in the format A/B (e.g., 2/6).
\item Use ruled engineering paper (physical or digital). Start each problem on a new page.
\item Show work in a logical order so another engineer can follow it. Use this structure: given data / diagram; required results; separator line; calculations / diagram; final answer (boxed).
\item Show steps with no big jumps. For repetitive calculations, one fully worked sample plus a table is acceptable.
\item Box final answers and include correct units on intermediate results and final results.
\end{enumerate}
